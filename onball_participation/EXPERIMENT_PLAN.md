# 球员有球参与预测实验计划

## 首轮问题与数据

给定球队和动作时刻，检验在同一个执行者分布下，个人历史能否改善其动作起点的九宫格预测。采用 Wyscout 英超 2017/18 的 266 场训练与 57 场开发验证比赛。使用原来的十类开放比赛动作，位置标签按目标球队进攻方向计算。报告可达比例，仅对可达样本计算联合损失。

旧验证集 64,975 个可达目标中有 6,954 个按目标起点排除了邻近记录。这是既有诊断的适用范围。首轮重新构造历史，重新训练模型。主视图隐藏同半场所有等时记录，前 2 秒内只保留严格早于目标的本方有球记录。时间敏感性视图要求同半场记录早于目标超过 2 秒。窗口、阶段、个人历史和候选人可见证据使用同一规则。真实起点、终点、执行者和目标 tag 仅用作标签或诊断。跨场履历按 UTC 日期更新，验证全程冻结在训练期末。

## 实验对照

每个种子先训练并固定执行者概率和局面表示，再训练同结构的位置预测头。

| 模型 | 特征 |
|---|---|
| A | 最近 32 条可见事件及球队局面 |
| B | A 加赛前位置组和按上一可见区域统计的位置组分布 |
| C | B 加候选人最近 32 次本场有球动作的区域、类型和参与间隔 |
| D | C 加前期个人区域分布，用位置组分布作 50 个伪观测平滑 |

主比较为 D 对 B。C 对 B 估计本场履历增益，D 对 C 估计跨场履历增益。对 D 在同队同位置组内交换个人特征并固定执行者概率。两秒延迟视图复跑 B 与 D。

## 评估与验收

三个种子为 20260715、20260716、20260717。各模型训练 120 轮，每 4 轮验证。执行者按验证执行者损失、位置头按验证条件区域损失选轮。主指标为联合负对数似然，另报执行者 Top-1、Top-3、条件区域损失和边缘区域损失。按种子配对取平均，按比赛重抽 10,000 次求 95% 区间。

从事件流改变固定查询的目标及后续记录，验证输入与候选人不变。检查联合分解和概率归一化，汇报每一视图的覆盖率。使用开发验证集得到的结论保留作开发证据。

## 后续路线

1. 在相同历史和预算下比较顺序模型与事件－球员－区域图。比较执行者与位置联合训练和单独训练执行者。
2. 将预测的球员与区域分布用于原十类事件。检查普通传球与 High pass、普通传球与 Touch 的混淆。分别开关历史技术标签与细标签监督，报告传中和射门部位。
3. 分别报告个人位置、执行者和事件预测的收益。模型与判据确定后再使用保留的时间测试集。

## 复算首轮

从本目录执行。两个视图分别将构建结果写入 results。输入为已有的 Wyscout 原始事件白名单表 events_in、赛前角色历史、换人和上场区间、比赛切分及标签。只使用目标元表中的球队和时钟构造查询。

```bash
for view in main lag; do
  python build.py --data ../scene_regularity_release/data/processed/England_nontest --out results --view "$view"
done
for seed in 20260715 20260716 20260717; do
  python train.py --data results/main.npz --out results/main_"$seed" --device cuda:0 --seed "$seed" --heads ABCD
  python train.py --data results/lag.npz --out results/lag_"$seed" --device cuda:0 --seed "$seed" --heads BD
done
python evaluate.py --results results
```

实现采用按时间排列的 32 个事件嵌入拼接至两层 MLP，结合候选人位置组和本场履历训练执行者。位置头使用冻结的 64 维局面编码、同宽的输入和 64 维隐藏层。A 至 D 对未启用的特征块置零。沿用旧工程的学习率日程和按场轮转采样器。组内交换沿候选编号循环一位，单人组保留原位。统计区间的抽样单位为比赛，损失按动作加权。

输入扰动验收可在建表后运行：

```bash
python check_views.py --data ../scene_regularity_release/data/processed/England_nontest --raw ../scene_regularity_release/data/raw --results results
```

训练配置为 256 样本每批，每场每轮轮转抽 128 个可达目标，AdamW 学习率 0.0027、权重衰减 0.0001、梯度裁剪 5。第 96、108 轮之后各将学习率乘 0.3。新增历史计数在同一天的全部查询生成之后才更新，样本来自训练期可达目标。没有个人历史的球员通过同一平滑公式继承位置组分布。

## 后续路线第 1 项的执行记录

执行者单任务与执行者－位置联合训练的配对对照已完成。主视图的三个种子均改善执行者概率，平均执行者 NLL 降低 0.0214，Top-1 提高 0.51 个百分点。统一延迟两秒时仍观察到同向改善。结果来自 57 场英超开发验证比赛。[实验协议](JOINT_PROTOCOL.md) · [完整结果](results/joint_training/RESULTS.md)
