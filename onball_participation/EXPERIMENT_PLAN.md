# 球员有球参与预测实验计划

## 首轮问题与数据

给定球队和动作时刻，检验在同一个执行者分布下，个人历史能否改善其动作起点的九宫格预测。采用 Wyscout 英超 2017/18 的 266 场训练与 57 场开发验证比赛。使用原来的十类开放比赛动作，位置标签按目标球队进攻方向计算。报告可达比例，仅对可达样本计算联合损失。

旧验证集 64,975 个可达目标中有 6,954 个按目标起点排除了邻近记录。这是既有诊断的适用范围。首轮重新构造历史，重新训练模型。主视图隐藏同半场所有等时记录，前 2 秒内只保留严格早于目标的本方有球记录。时间敏感性视图要求同半场记录早于目标超过 2 秒。窗口、阶段、个人历史和候选人可见证据使用同一规则。真实起点、终点、执行者和目标 tag 仅用作标签或诊断。跨场履历按 UTC 日期更新，验证全程冻结在训练期末。

## 实验对照

每个种子先训练并固定执行者概率和局面表示，再训练同结构的位置预测头。

| 模型 | 特征 |
|---|---|
| A | 最近 32 条可见事件及球队局面 |
| B | A 加赛前位置组和按上一可见区域统计的位置组分布 |
| C | B 加候选人最近 32 次本场有球动作的区域、类型和参与间隔 |
| D | C 加前期个人区域分布，用位置组分布作 50 个伪观测平滑 |

主比较为 D 对 B。C 对 B 估计本场履历增益，D 对 C 估计跨场履历增益。对 D 在同队同位置组内交换个人特征并固定执行者概率。两秒延迟视图复跑 B 与 D。

## 评估与验收

三个种子为 20260715、20260716、20260717。各模型训练 120 轮，每 4 轮验证。执行者按验证执行者损失、位置头按验证条件区域损失选轮。主指标为联合负对数似然，另报执行者 Top-1、Top-3、条件区域损失和边缘区域损失。按种子配对取平均，按比赛重抽 10,000 次求 95% 区间。

从事件流改变固定查询的目标及后续记录，验证输入与候选人不变。检查联合分解和概率归一化，汇报每一视图的覆盖率。使用开发验证集得到的结论保留作开发证据。

## 接下来的实验顺序

第一、二步的 30 组训练已完成。逐项结果和据此确定的第三步见[十三类事件实验执行记录](#十三类事件实验执行记录)。

**第一步，建立当前视图的顺序事件基线。** 以同一可见历史、球队和时刻各训练一个情境头，分别直接预测十三类和折叠后的十类。直接十类头用于回答“细分监督能否改善粗类预测”。十三类头用于后续所有球员信息对照。实现时先复核无特征参照：主视图按 302,919 条可达训练动作的类别频率预测 64,975 条可达验证动作，十三类 NLL 为 2.0888，折叠十类为 1.5142，普通传球条件方向 NLL 为 1.0056。

**第二步，固定上游球员模型，区分区域和个人的贡献。** 每个视图、每个种子用对应联合训练权重，推断有效候选人的执行概率及其条件起点分布，相乘得到“候选球员 × 九宫格”联合分布。保存概率和候选顺序，按比赛与事件 ID 对齐。比较以下四种十三类预测，事件头沿用同一历史编码结构、训练样本、采样顺序和参数预算。

| 对照 | 预测时使用的信息 | 所检验的增量 |
|---|---|---|
| 仅局面 | 此前可见的比赛历史、目标球队和时刻 | 顺序基线 |
| 局面＋预测区域 | 对各区域的事件概率按预测的边缘区域分布求和 | 预测出的动作起点能否帮助判断动作类型 |
| 加位置组倾向 | 按同一个球员－区域联合分布，汇总各候选人位置组在该区域的动作倾向 | 可能参与的球员角色能解释多少 |
| 加个人倾向 | 在上组相同权重下，用个人在该区域的十三类动作频率，向其位置组分布平滑 | 同区域、同角色下，球员自己的出球选择是否有增量 |

条件事件头在训练时用真实执行者、起点选中对应分支计算损失。正式验证对所有候选人和区域按预测概率求和。位置组和个人的动作频率按早于查询日的训练记录累计，验证期冻结。个人频率用 50 个位置组伪观测平滑，未见球员沿用位置组分布。组内交换个人倾向作为配对对照，固定球员与区域概率。真实起点或真实执行者另作诊断，用来定位预测区域或执行者的不确定性损失。目标终点只用于构造标签。

**判据。** 主指标为主视图十三类事件 NLL，以“加位置组倾向”对“加个人倾向”的配对改善衡量个人贡献。另报十三类 Macro-F1、各类支持数和混淆矩阵。对同一组十三类概率，将四类普通传球概率相加后计算十类 NLL；在真实普通传球上，将这四个概率按其和归一化，计算条件方向 NLL。可核对下式，其中主视图普通传球占比为 37,127 / 64,975：

```text
十三类 NLL = 折叠十类 NLL + 普通传球占比 × 条件方向 NLL
```

分别检查变化来自方向选择还是粗类判断，并检查普通传球与 Touch、长传的双向误判；长传召回另按真实 High pass 和 Launch 拆分。沿用三个种子、相同的训练预算和选轮规则（事件头按开发集事件 NLL）。每个视图在相同可达动作上做模型间配对，按比赛重抽 10,000 次给出 95% 区间，列出逐种子差值；主视图和两秒视图直接比较时用共同可达的 64,966 个动作。比较结束、方法确定后再使用保留的时间测试集。

**第三步，根据收益安排图与历史输入消融。** 若同角色球员的个人倾向在预测条件下仍改善事件 NLL，优先检验已观测的“球员－动作－区域”关系在同信息、同预算下是否优于充分训练的顺序模型。若改善集中在已知执行者或已知起点的诊断，优先定位哪项上游不确定性限制传递；若只有传球方向改善，就将结论限定到方向选择。图对执行者／位置主任务的作用仍可独立比较。将已完成的历史传球方向加入输入属于另一项消融，届时核查该终点在查询时已可见，重训实际读取新特征的模型及其配对对照。历史技术标签与细标签辅助监督分别开关。

## 十三类事件标签

事件任务把 Wyscout 的 `Pass / Simple pass` 分成四个一级类别。其余九类沿用十类动作表的名称和编号，包括高球／Launch、传中、Smart pass 和头球传递。主视图和两秒延迟视图的每个目标事件都有同一个标签，按各自的候选集统计执行者可达样本。

在 Wyscout 的 0–100 坐标上，进攻沿 x 轴正向。采用 105 × 68 米球场，令 `u = 1.05 × (终点x − 起点x)`、`v = 0.68 × (终点y − 起点y)`，单位为米。

| 标签 | 编号 | 判据 |
|---|---:|---|
| 前向普通传球 | 0 | u > 0，纵向位移绝对值大于或等于横向位移绝对值 |
| 后向普通传球 | 10 | u < 0，纵向位移绝对值大于或等于横向位移绝对值 |
| 横向普通传球 | 11 | 横向位移绝对值大于纵向位移绝对值，含短横传 |
| 原地普通传球 | 12 | 两个有效端点的 x 和 y 均相同 |

45° 边界归纵向，按 u 的符号分为前向或后向。普通传球的起终点均须为 0–100 内的有效坐标，缺失或越界时建表报出事件 ID。目标坐标只参与制作标签，预测使用动作发生前可见的历史。

下方建表命令生成的 `results/main.npz` 与 `results/lag.npz` 含逐行动作编号 `action13` 和按编号排列的类别名 `action13_names`，通过 `event` 对齐事件 ID。十三类是事件模型的主输出。需要十类结果时，将 0、10、11、12 四列概率相加得到普通传球概率。输入扰动验收同时逐事件回查 Wyscout 原始记录，各视图的训练与开发验证计数见[验收结果](results/view_checks.json)。

## 复算首轮

从本目录执行。使用归档输入时，先合并两个视图的分片，再从训练循环开始。[仓库使用说明](../README.md#使用方法)

从原始记录建表时，两个视图分别将构建结果写入 results。输入为已有的 Wyscout 原始事件白名单表 events_in、赛前角色历史、换人和上场区间、比赛切分及标签。只使用目标元表中的球队和时钟构造查询。

```bash
for view in main lag; do
  python build.py --data ../scene_regularity_release/data/processed/England_nontest --out results --view "$view"
done
for seed in 20260715 20260716 20260717; do
  python train.py --data results/main.npz --out results/main_"$seed" --device cuda:0 --seed "$seed" --heads ABCD
  python train.py --data results/lag.npz --out results/lag_"$seed" --device cuda:0 --seed "$seed" --heads BD
done
python evaluate.py --results results
```

实现采用按时间排列的 32 个事件嵌入拼接至两层 MLP，结合候选人位置组和本场履历训练执行者。位置头使用冻结的 64 维局面编码、同宽的输入和 64 维隐藏层。A 至 D 对未启用的特征块置零。沿用旧工程的学习率日程和按场轮转采样器。组内交换沿候选编号循环一位，单人组保留原位。统计区间的抽样单位为比赛，损失按动作加权。

输入扰动验收可在建表后运行：

```bash
python check_views.py --data ../scene_regularity_release/data/processed/England_nontest --raw ../scene_regularity_release/data/raw --results results
```

训练配置为 256 样本每批，每场每轮轮转抽 128 个可达目标，AdamW 学习率 0.0027、权重衰减 0.0001、梯度裁剪 5。第 96、108 轮之后各将学习率乘 0.3。新增历史计数在同一天的全部查询生成之后才更新，样本来自训练期可达目标。没有个人历史的球员通过同一平滑公式继承位置组分布。

## 十三类事件实验执行记录

复用六个执行者与区域联合训练检查点，在主视图及延迟两秒视图各运行五组事件模型、三个种子。条件事件头在正式推断时固定使用上游预测的球员与区域概率。主视图有 64,975 个可达验证动作，以下损失单位为 nats。模型选轮和本轮评分均使用 57 场开发验证比赛。[实验协议与复算命令](EVENT_PROTOCOL.md) · [完整结果与混淆分析](results/event13/RESULTS.md)

1. **保留十三类事件目标。** 仅看比赛局面时，直接训练十类的 NLL 为 1.2506。训练十三类再合并四种普通传球，十类 NLL 为 1.2480，按比赛配对的降幅为 0.0026，95% 区间为 [0.0016, 0.0037]。延迟视图的降幅为 0.0016。
2. **同位置组内的个人差异有下游价值。** 仅局面、加区域、加位置组、加个人的十三类 NLL 依次为 1.8134、1.8070、1.8044、1.7981。个人相对位置组改善 0.0063，95% 区间为 [0.0052, 0.0074]，延迟视图改善 0.0058。同一模型只交换同队同位置组球员的个人档案，主视图损失增加 0.0035。
3. **主要收益在动作大类。** 每个验证动作的改善中，粗类判断贡献 0.00534，普通传球方向贡献 0.00092。按真实大类分解，Touch 和普通传球分别贡献 0.00210 和 0.00207。已知为普通传球时，个人模型对前向、后向、横传的召回率分别为 3.18%、1.85%、97.96%。原地传球共 18 条。保留方向条件 NLL，并逐方向报告类别偏好。
4. **下一次图对照先检验执行者。** 个人相对位置组的十三类 NLL 优势在给定真实执行者时扩大到 0.0192，单独给定真实区域时为 0.0070。现有 `token` 序列记录动作子类与球队归属，`hist` 是每名候选人的汇总。下一组从同一批可见事件取出每个历史动作的执行者与起点区域，同时提供给顺序对照和图模型。图只连接已观测的执行者、动作与区域；顺序对照在同样的 32 条历史记录上保留相同的候选人对应关系。沿用三个种子、相同训练预算和按执行者 NLL 选轮，先比较执行者及球员－区域联合 NLL，再将两组预测分布分别送入本轮冻结的个人事件头，检验上游改善能否传给十三类事件。历史传球方向输入与目标 tag 辅助监督在各自独立的对照中检验。
