# 球员与区域信息对十三类事件预测的配对实验

给定球队和动作时刻，预测下一次开放比赛动作。数据来自英超 266 场训练和 57 场开发验证比赛。使用[已核验的十三类标签和两种可见历史](EXPERIMENT_PLAN.md#十三类事件标签)。每个视图单独取执行者可达的动作，使所有对照按相同的比赛、事件和候选集评分。

## 模型和对照

各组从头训练同结构的 32 步顺序编码器，沿用球员实验的事件嵌入、区域嵌入、事件年龄、球队情境和两层 MLP。历史坐标使用此前可见记录的起点。十三类各组使用同尺寸的输出层、区域偏置和动作倾向投影，按实验组启用相应项。类别 logit 由情境 logit、可选的区域偏置、可选的出球频率投影相加得到。模型之间的差异由逐步增加的可用信息解释，条件分支的训练及推断方式也会影响结果。

| 训练组 | 训练损失 | 正式推断 |
|---|---|---|
| 直接十类 | 四类普通传球合并后做十类交叉熵 | 直接输出十类分布 |
| 十三类仅局面 | 十三类交叉熵 | 直接输出十三类分布 |
| 加预测区域 | 给定真实起点区域，计算该分支的十三类交叉熵 | 用预测的边缘区域概率加权 |
| 加位置组倾向 | 监督真实候选球员、区域对应的条件分支，使用其位置组在该区域的动作频率 | 用预测的球员与区域联合概率混合条件分布 |
| 加个人倾向 | 同上，换成该球员在该区域的平滑频率 | 复用与位置组对照相同的球员与区域联合概率 |

每个视图和种子都使用对应的执行者－位置联合训练检查点。记录候选顺序及其 11 × 9 联合概率，并用真实执行者与区域的联合负对数概率核对原运行逐动作评分。条件事件模型分别拟合每个分支，在开发集上按预测条件下的混合分布选轮。上下游均曾在该开发期选轮，配对区间反映比赛间差异。

出球频率来自同视图可达的训练动作，按 UTC 日期在整日预测完成后更新。先对各区域的总体类别计数每类加一，再用该分布为每个位置组提供 50 个伪观测；个人频率继承所在位置组的 50 个伪观测。模型输入为上述 13 维频率取对数后减去各类别对数的均值。验证全期采用训练期末的计数。球员 ID 用于查找个人历史及对齐候选人。验证时在同队同位置组内轮换个人倾向，单人组保留原位。另用真实执行者、真实区域或两者选择／归一化对应的分支权重，作为诊断。

## 训练和评估

三种子为 20260715、20260716、20260717。每组 120 轮，每轮每场轮转抽 128 次，batch 256，末批按实际大小；AdamW 学习率 0.0027、权重衰减 0.0001、梯度裁剪 5，第 96、108 轮后学习率各乘 0.3。每四轮按本组输出粒度的开发集事件 NLL 选轮，配对条件使用相同抽样顺序、初始化种子与优化预算。

主比较为主视图的位置组 NLL 减个人 NLL，包含改用个人倾向并重新拟合事件头的效果。组内交换保持同一个人的执行概率、各区域权重和事件模型参数固定，只交换同组队友的个人动作倾向，用于单独检查档案与候选球员的对应关系。真实条件诊断也使用正式选中的权重。

十三类概率折叠到十类时，先相加四类普通传球概率，再计算十类损失和最大概率类别。普通传球条件方向 NLL 在真实普通传球上计算，将四项概率除以其和。逐动作验证损失分解，按种子分别评分、报告逐种子差值，并按比赛配对重抽 10,000 次给出区间。折叠混淆中，High pass 和 Launch 是真实长传的两个 Wyscout 子类，分别报告长传召回率以及误判为普通传球的比例。每种子的完整矩阵按真实类为行、预测类为列。方向矩阵依次为前向、后向、横传、原地。

## 复算

在本目录按仓库使用说明合并两个视图的分片。每个运行目录包含上游验证联合概率、五个事件头的最优权重、选轮曲线和逐动作验证概率。归档还提供 323 场比赛的日期与划分，以及 65,133 个开发验证目标的比赛编号、事件编号和 Wyscout 动作子类。[使用方法](../README.md#使用方法)

用归档概率复算报告时执行以下命令。

```bash
python evaluate_events.py --data results --runs results/event13 --events results/event13/inputs/events_in.parquet
```

重新训练时，将输出写入新的运行目录。

```bash
data=results/event13/inputs
runs=results/event13_rerun
for view in main lag; do
  for seed in 20260715 20260716 20260717; do
    python train_events.py --data results/"$view".npz --matches "$data"/matches.parquet \
      --upstream results/joint_training/"${view}_joint_${seed}" \
      --out "$runs"/"${view}_${seed}" --seed "$seed" --device cuda:0
  done
done
python evaluate_events.py --data results --runs "$runs" --events "$data"/events_in.parquet
```

运行 `python -B test_event_inputs.py` 可检查同日训练标签隔离、验证期冻结、未见球员继承位置组倾向，以及更换验证真实执行者和区域只会改变诊断结果。
